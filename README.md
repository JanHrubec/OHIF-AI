# OHIF-AI

My fork of [CCI-Bonn/OHIF-AI](https://github.com/CCI-Bonn/OHIF-AI), an OHIF-based viewer with server-side AI segmentation and reporting. Used for ceramic CT research during my ÚTIA internship.

See [upstream setup, models and credits](README-GUIDE.md). Requires Docker and the appropriate GPU/model configuration.
